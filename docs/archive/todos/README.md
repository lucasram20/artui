# Archived: docs/todos/

This directory was migrated to the **artui project board** on
[github.com/users/lucasram20/projects/2](https://github.com/users/lucasram20/projects/2).

Each phase ticket here lives as a GitHub Issue with a copy of the original
markdown body, plus structured fields:

- **Status** — Todo / In Progress / Done
- **Phase** — A..N4, parking-lot, infra
- **Workstream** — harness-core, lsp, sandbox, indexer, etc.
- **Priority** — P0..P3
- **Size** — XS..XL (from "Estimated PR size" in the original doc)
- **Shipped In** — version tag for closed issues

The markdown files are kept here for git-history traceability and as
long-form spec references — the project board is the source of truth for
status going forward.

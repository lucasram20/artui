# Agent Defaults

- Use ultra-concise, token-saving responses by default.
- Prefer short bullet points over long prose.
- Ask only essential follow-up questions.
- Avoid redundant explanations unless explicitly requested.

## Backlog & feature management

Backlog, feature requests, and phase tracking live on the GitHub Project board — not in markdown:

- **Project**: https://github.com/users/lucasram20/projects/2
- **Issues**: https://github.com/lucasram20/artui/issues

When proposing new work, file a GitHub issue (`gh issue create`) and add it to the project. Don't create new files under `docs/todos/` — that directory has been archived to `docs/archive/todos/` for historical spec reference only.
